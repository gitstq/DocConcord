# 📋 规则清单 · Rule Catalog

共 **18 条**规则，按四个规则族组织。运行 `docconcord rules` 可在终端查看同一清单。

## 结构 S

| ID | 级别 | 含义 |
| --- | --- | --- |
| S001 | error | 译文缺少基准文档中存在的章节 |
| S002 | warning | 译文存在基准文档没有的额外章节 |
| S003 | error | 对应章节的标题层级（H1–H6）不一致 |
| S004 | warning | 共有章节的相对顺序与基准文档不一致（仅别名表模式） |

## 内容 B

| ID | 级别 | 含义 |
| --- | --- | --- |
| B001 | error | 围栏代码块数量不一致 |
| B002 | warning | 同一位置代码块的语言标注不同 |
| B003 | info | 代码块未标注语言（无法参与一致性校验） |
| B004 | error | 表格数量不一致 |
| B005 | warning | 同一位置表格的行数或列数不同 |
| B006 | warning | 可复制命令条数不一致 |
| B007 | warning | 同一位置命令内容与基准不同 |

## 链接 L

| ID | 级别 | 含义 |
| --- | --- | --- |
| L001 | warning | 两个语言版本的外部链接集合存在差异 |
| L002 | error | 锚点（同文档或跨文件）不存在 |
| L003 | error | 本地链接目标文件不存在 |

## 安全 X

| ID | 级别 | 含义 |
| --- | --- | --- |
| X001 | error | 危险示例命令：`curl … \| sh`、`rm -rf /`、`chmod 777`、`dd if=`、`mkfs`、`eval` 等 |
| X002 | error | 疑似硬编码凭据：`ghp_*`、`sk-*`、`AKIA*`、`password = "…"` 等 |

> X002 是提醒，不是密钥扫描器的替代品。发现真实凭据请**立即轮换**。

## 门禁与豁免

| `--fail-on` | 触发失败的级别 |
| --- | --- |
| `error`（默认） | 仅 error |
| `warning` | warning + error |
| `info` | 任意发现项 |
| `never` | 永不失败 |

在 `.docconcord.json` 的 `disabled_rules` 中列出规则 ID 即可豁免，例如：

```json
{
  "disabled_rules": ["L004", "B003"]
}
```

也可以用 `--disable L004` 单次豁免。建议**优先修复**而非豁免，并在 PR 描述里说明理由。

## 退出码

| 码 | 含义 |
| --- | --- |
| 0 | 门禁通过 |
| 1 | 存在达到阈值的发现项 |
| 2 | 运行错误（路径不存在、配置无法解析、文件不可读） |
